🌐 تعلم HTML







الدرس 1: ما هي HTML؟




HTML هي اللغة التي نستخدمها لبناء هيكل صفحات الويب.




<h1>مرحبًا بك في UDH</h1>

<p>أنا أتعلم HTML</p>













الدرس 2: العناوين




نستخدم h1 إلى h6 لإنشاء العناوين.




<h1>عنوان كبير</h1>

<h2>عنوان أصغر</h2>













الدرس 3: الفقرات




نستخدم الوسم p لكتابة الفقرات.




<p>
هذه فقرة في موقعي
</p>
























🎨 تعلم CSS







الدرس 1: ما هي CSS؟




CSS تستخدم لتنسيق وتصميم المواقع.




body {
    background: black;
    color: white;
}













الدرس 2: الألوان



h1 {
    color: red;
}
