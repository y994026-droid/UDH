🌐 تعلم HTML

تعلم إنشاء صفحات المواقع من الصفر.

📚 الدرس 1: ما هي HTML؟

HTML هي اللغة التي نستخدمها لإنشاء هيكل صفحات الويب. 

<h1>مرحبًا بك في UDH</h1>

<p>أنا أتعلم HTML</p>

📝 الدرس 2: العناوين

نستخدم h1 إلى h6 لإنشاء العناوين. 

<h1>عنوان كبير</h1>

<h2>عنوان أصغر</h2>

<h3>عنوان</h3>

📄 الدرس 3: الفقرات

نستخدم الوسم p لكتابة النصوص والفقرات. 

<p>هذه فقرة في موقعي</p>

🔗 الدرس 4: الروابط

نستخدم a لإنشاء الروابط. 

<a href="https://example.com">

اضغط هنا

</a>

🖼️ الدرس 5: الصور

نستخدم img لإضافة الصور. 

<img src="image.jpg" alt="صورة">

📋 الدرس 6: القوائم

يمكنك إنشاء قائمة باستخدام ul و li. 

<ul>

<li>HTML</li>

<li>CSS</li>

<li>JavaScript</li>

</ul>

🔘 الدرس 7: الأزرار

<button>

اضغط هنا

</button>

📦 الدرس 8: الأقسام

نستخدم div لتجميع العناصر داخل الصفحة. 

<div>

<h2>عنوان</h2>

<p>نص</p>

</div>

📝 الدرس 9: النماذج

<form>

<input type="text">

<button>إرسال</button>

</form>

🎯 الدرس 10: تحدي HTML

أنشئ صفحة تحتوي على عنوان وفقرة وصورة ورابط وزر.

📚 الدرس 1: ما هي CSS؟

CSS تستخدم لتنسيق وتصميم صفحات المواقع.

🎨 الدرس 2: الألوان

h1 {

color: red;

}

🔲 الدرس 3: الخلفيات

body {

background-color: black;

}

📏 الدرس 4: حجم الخط

font-size: 20px;

}

✏️ الدرس 5: نوع الخط

font-family: Arial;

}

📦 الدرس 6: الحدود

div {

border: 2px solid red;

}

↔️ الدرس 7: المسافات

div {

margin: 20px;

padding: 20px;

}

🔘 الدرس 8: الأزرار

button {

background: blue;

color: white;

padding: 10px 20px;

border-radius: 10px;

}

📐 الدرس 9: Flexbox

.container {

display: flex;

justify-content: center;

}

🧱 الدرس 10: Grid

.container {

display: grid;

grid-template-columns: 1fr 1fr;

}

📱 الدرس 11: تصميم الموبايل

@media (max-width: 600px) {

body {

font-size: 16px;

}

}
